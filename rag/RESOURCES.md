# RagLab resources

Further reading on embeddings, retrieval and context selection.

- [Introducing text and code embeddings — OpenAI](https://openai.com/index/introducing-text-and-code-embeddings/) — An introduction to representing text as vectors for similarity and semantic search.
- [Question answering using embeddings-based search — OpenAI Cookbook](https://developers.openai.com/cookbook/examples/question_answering_using_embeddings) — An API-based walkthrough of chunking documents, ranking passages and using retrieved text to answer questions.
- [Introducing Contextual Retrieval — Anthropic](https://www.anthropic.com/research/contextual-retrieval) — Explains how adding context to chunks, combining semantic and keyword search, and reranking can improve retrieval.
- [Effective context engineering for AI agents — Anthropic](https://www.anthropic.com/research/effective-context-engineering-for-ai-agents) — Discusses selecting relevant information within a model's context budget, including retrieval strategies.
- [AI Insights: RAG Systems — GOV.UK](https://www.gov.uk/government/publications/ai-insights/ai-insights-rag-systems-html) — An overview of the RAG workflow, benefits, limitations and evaluation methods.
- [AI Insights: Agentic RAG — GOV.UK](https://www.gov.uk/government/publications/ai-insights/ai-insights-agentic-rag-html) — Explains how agents iteratively retrieve information and refine answers, with the associated risks and trade-offs.
