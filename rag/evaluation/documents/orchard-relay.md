# Orchard telemetry relay

The Orchard telemetry relay connects soil sensors at Vesper Farm. Firmware OR-9.4 was approved by Nila Quill on 3 March 2032. The radio channel is 17. Packets are sent every ninety seconds. A relay restart requires holding the square button for eight seconds. The gateway enclosure is green. This network carries measurements from apple trees, not customer orders. Maintenance records use the prefix OTR.
